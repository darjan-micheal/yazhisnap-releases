Windows installers for [YazhiSnap](https://yazhisoftwaresolutions.com/products/yazhisnap/), the live event photo gallery from [Yazhi Software Solutions](https://yazhisoftwaresolutions.com/).

The newest installer is under [Releases](https://github.com/darjan-micheal/yazhisnap-releases/releases/latest), or on our [download page](https://yazhisoftwaresolutions.com/products/yazhisnap/download/), which also shows its SHA-256.

## Installing

1. Download `YazhiSnap_<version>_x64-setup.exe` from the newest release.
2. Compare the file's SHA-256 with the one on the download page. In PowerShell: `Get-FileHash .\YazhiSnap_<version>_x64-setup.exe`
3. Open the file. Windows may show "Windows protected your PC", because the installer does not have a paid Windows certificate yet. If the SHA-256 matches, choose **More info**, then **Run anyway**.

The app is free to download. Starting an event needs a QR Event key: see [plans and prices](https://yazhisnap.yazhisoftwaresolutions.com/plans).
